FrontDesk

FrontDesk is an open-source inbox agent I built and run on my own mail. It reads my inbox, ranks what actually needs me, says why in one line, and has a reply drafted for the threads that want one. It runs on my own computer with the model I choose.

The code is on GitHub: [link once the repository is public]. A demo with a synthetic inbox runs in 30 seconds with no Google account and no API key.

How I know it works

I measure it. The repository holds 80 labeled synthetic threads and 32 prompt-injection attacks (mail that tries to talk the model into misfiling it, or into putting the attacker's words into my reply). Across four Claude models, none filed a thread that needed me under "ignore". The default model is the cheapest one that clears every safety floor; the full table, with confidence intervals, is in the repository.

Privacy policy

What FrontDesk is. FrontDesk is software you run on your own computer. There is no FrontDesk server, no FrontDesk account and no analytics. The "FrontDesk" app on Google's sign-in screen is my own Google Cloud project, which I use with my own Gmail account.

What it reads from Google. With the read-only permission, FrontDesk reads the Gmail threads that match a search you set (by default, your inbox from the last seven days). If you grant the separate actions permission, it can also archive a thread, move it back to your inbox, and create drafts. It never sends mail.

Where your data goes. FrontDesk keeps the threads it syncs, its rankings and your Google sign-in tokens on your computer, in a folder only your user account can read. It sends data to two places only: to Google, to read your mail and, if you allow it, to archive threads and save drafts; and to the AI model provider you configure, which receives the plain text of each thread so it can rank it and suggest a reply. Message formatting (HTML) and attachments are not sent to the model provider. That provider's own data terms apply to what it receives.

What it never does. FrontDesk does not sell, share or advertise with your data, does not use it to train models, and does not send it anywhere except the two places above.

Google API data. FrontDesk's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting. Threads you archive, or that leave your inbox, are removed from FrontDesk's local store on the next sync. Deleting the ~/.frontdesk folder removes everything FrontDesk has stored. To revoke its access to your Google account, remove it at myaccount.google.com/permissions.
