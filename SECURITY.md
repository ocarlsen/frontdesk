# Security Policy

## Supported versions

Only the `main` branch is supported. Fixes land there; there are no maintained release branches.

## Reporting a vulnerability

Report privately via GitHub Security Advisories on this repository
("Security" tab, then "Report a vulnerability"). Please do not open a public issue for a
security problem.

Include what you found, how to reproduce it, and the impact you expect. You will get an
acknowledgement once the report is read.
